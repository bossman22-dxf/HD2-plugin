HELLDIVERS 2 StreamController Plugin — New Stratagem Workflow
=============================================================

Use this checklist when Arrowhead adds a stratagem and you want to update this
plugin while keeping the HD2-* action/icon naming style.

Plugin/project directory
------------------------
$HOME/.var/app/com.core447.StreamController/data/plugins/bossman22-dxf_HD2

Styled icon source directory
----------------------------
$HOME/Pictures/Icons

Use $HOME in commands or ~/ in documentation rather than hard-coding a
particular user's /home/... directory.

Important notes
---------------
1. Run update commands in a normal host terminal from this project directory,
   not inside the StreamController Flatpak sandbox.
2. StreamController only needs the finished PNG files in assets/icons at
   runtime; cairosvg is only needed by the update scripts for SVG fallback.
3. Prefer the styled PNGs in $HOME/Pictures/Icons. The icon generator ignores
   these subdirectories for stratagem styling: Factions, Folder Icons, and Keys.
4. Canonical action/icon IDs use the HD2-* naming style. Example:
   Eagle Gas Airstrike is HD2-EGA.
5. This plugin directory is the installed plugin location. Do not use the old
   net_jslay_helldivers_2 path.

One-time setup / dependency refresh
-----------------------------------
Run from the project directory:

  cd "$HOME/.var/app/com.core447.StreamController/data/plugins/bossman22-dxf_HD2"
  python3 -m venv .venv
  source .venv/bin/activate.fish
  python -m pip install -r update/requirements.txt

Fish shell note: use source .venv/bin/activate.fish. If you prefer not to
activate the virtual environment, call its interpreter directly:

  .venv/bin/python -m update validate

New stratagem update process
----------------------------
1. Open a Fish terminal and enter the plugin directory:

  cd "$HOME/.var/app/com.core447.StreamController/data/plugins/bossman22-dxf_HD2"
  source .venv/bin/activate.fish

2. Discover new wiki/SVG entries:

  python -m update discover -v

3. Add the stratagem to update/config.py.

   Add an entry to STRATAGEM_MAPPINGS using the exact wiki and SVG names:

     "EagleGasAirstrike": {
         "wiki": "Eagle Gas Airstrike",
         "svg": "Eagle Gas Airstrike",
         "name": "Eagle Gas Airstrike",
     },

   Add its canonical ID to HD2_KEY_OVERRIDES in the same file:

     "EagleGasAirstrike": "HD2-EGA",

   Choose a short, consistent HD2-* identifier.

4. Add the finished 144x144 styled PNG under $HOME/Pictures/Icons in the
   correct category. Do not put it under Factions, Folder Icons, or Keys.
   The filename stem must match the HD2-* ID:

     $HOME/Pictures/Icons/Eagle/HD2-EGA.png

5. Regenerate stratagem sequences from the wiki:

  python -m update stratagems -v

   This updates assets/data/stratagems.json.

6. Regenerate locale labels:

  python -m update locales

   This updates locales/en_US.json.

7. Generate/copy icons:

  python -m update icons

   Matching styled PNGs are copied from $HOME/Pictures/Icons. If no local PNG
   exists, the script falls back to SVG rendering when cairosvg and Cairo are
   available in the host environment.

8. Validate:

  python -m update validate

   Resolve missing icon warnings for canonical stratagem keys. Extra icon
   warnings may indicate stale files or navigation/organization icons.

9. Optional: generate test pages:

  python -m update pages

10. Restart StreamController if it was running, then add and test the action
    on the Stream Deck.

Quick command sequence
----------------------
After editing update/config.py and adding the styled PNG:

  cd "$HOME/.var/app/com.core447.StreamController/data/plugins/bossman22-dxf_HD2"
  source .venv/bin/activate.fish
  python -m update stratagems -v
  python -m update locales
  python -m update icons
  python -m update validate

Flatpak / CachyOS Cairo note
----------------------------
If cairosvg reports that it cannot load the cairo library, the environment
running it cannot access the Cairo system library. Host packages alone may not
satisfy libraries inside a Flatpak sandbox. Run update scripts from the host
terminal and project virtual environment; StreamController only needs the
generated PNG files at runtime.
